# BBjShip

BBjShip is the BBj plugin that deploys webforJ apps to BBjServices. Builds deploy apps through its deployment endpoint, and the `bbjship` command line manages them on the server.

## Installing

Install BBjShip from this repository with the [BBj Plugin Manager](https://documentation.basis.cloud/BASISHelp/WebHelp/bbutil/BBj_Plugin_Manager.htm). A tag installs a webforJ release, and `master` installs the development snapshot.

## Documentation

See the [BBjShip documentation](https://docs.webforj.com/docs/configuration/bbjship/overview).
